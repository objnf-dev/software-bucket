# Software Bucket

A personal bucket for [Scoop](https://scoop.sh), the Windows command-line installer.

## Software

| Package | Description |
| --- | --- |
| [`batteryhub`](https://github.com/ferloom/Wireless-Device-Battery-Monitor) | Show wireless device battery levels on the Windows taskbar. |
| [`easylpac`](https://github.com/creamlike1024/EasyLPAC) | A GUI LPA for managing eSIMs on removable eUICCs. |
| [`hapsign`](https://github.com/guantw/HapSign) | Auto debug-signing and installation of HarmonyOS HAP packages. |
| [`pake-excalidraw`](https://github.com/tw93/Pake) | A lightweight Excalidraw desktop client built with Pake. |
| [`pake-genshincloud`](https://github.com/objnf-dev/software-bucket-bin) | A lightweight Genshin Impact Cloud desktop client built with Pake. |
| [`pake-gtranslate`](https://github.com/objnf-dev/software-bucket-bin) | A lightweight Google Translate desktop client built with Pake. |
| [`pake-hsrcloud`](https://github.com/objnf-dev/software-bucket-bin) | A lightweight Honkai: Star Rail Cloud desktop client built with Pake. |
| [`pake-twitter`](https://github.com/tw93/Pake) | A lightweight X (Twitter) desktop client built with Pake. |
| [`pake-xiaohongshu`](https://github.com/tw93/Pake) | A lightweight XiaoHongShu desktop client built with Pake. |
| [`pfstat`](https://github.com/objnf-dev/windows-pagefile-viewer) | View Windows pagefile usage in a Linux swap-style table. |
| [`quiet-md`](https://github.com/s1dashu/quiet-md) | A fast, local-first rich-text notes app built with Rust and GPUI. |
| [`raven`](https://github.com/mjishnu/Raven) | A free, open-source alternative Microsoft Store client for Windows. |
| [`revo-registry-cleaner`](https://www.revouninstaller.com/products/revo-registry-cleaner-free/) | Clean, tune, and optimize the Windows Registry safely. |
| [`vda-off`](https://github.com/objnf-dev/software-bucket/blob/master/scripts/vda-off.ps1) | Disable GameViewer, MuMu, and Oray virtual display adapters. |

## Installation

Add the bucket, then install a package from the list above:

```pwsh
scoop bucket add software-bucket https://github.com/objnf-dev/software-bucket
scoop install software-bucket/raven
```
