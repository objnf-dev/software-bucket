# Software Bucket

**简体中文** | [English](README.en.md)

适用于 Windows 命令行安装工具 [Scoop](https://scoop.sh) 的个人软件仓库（Bucket）。

## 安装

添加此 Bucket，然后安装上表中的软件包：

```pwsh
scoop bucket add software-bucket https://github.com/objnf-dev/software-bucket
scoop install software-bucket/raven
```
